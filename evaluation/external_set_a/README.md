# External Validation Pack V1

This pack uses synthetic claim facts and original AwanSolveAi-generated layouts.
The field vocabulary and workflow structure were derived from public warranty-claim pages/forms,
but no OEM/dealer logo or exact original form artwork is reproduced.

Source families:
- Blue Giant public warranty claim form / procedure
- ANA public generator warranty claim form
- H&S Manufacturing public warranty claim request
- RockZone Americas public warranty claim form
- K-Tec public scraper warranty claim form

Purpose:
Blind-test the unchanged AwanSolveAi V0.3 parser against terminology and document structures
that differ materially from the internal development templates.

Important:
All claim facts are synthetic. None of these documents are actual warranty submissions.
